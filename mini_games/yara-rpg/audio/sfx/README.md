# Efeitos sonoros

Adicione os arquivos MP3 nesta pasta com estes nomes. O jogo já aponta para eles:

- `dodge.mp3`: esquiva bem-sucedida de Zeph
- `parry.mp3`: aparo bem-sucedido
- `basic-attack.mp3`: ataque rápido
- `special-attack.mp3`: estocada pesada ou golpe crítico
- `level-up.mp3`: subida de nível

Se quiser usar outros nomes, altere os caminhos no objeto `SOUND_EFFECTS` em `js/game.js`.
